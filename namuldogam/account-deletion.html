기존 계정 및 데이터 삭제

시행일: 2026-09-15 · 운영: Minsuk Kim

이 안내가 필요한 경우

최신 나물대사전은 클라우드 백업·로그인·계정 기능을 제공하지 않습니다. 이전 버전에서 Firebase 백업 계정을 사용한 이용자의 온라인 데이터와 계정은 2026년 9월 15일 기준 운영자가 모두 삭제했습니다(계정 0개 확인). 일반 도감·로컬 일기 이용만 했고 온라인 계정을 만든 적이 없다면 삭제할 클라우드 계정이 없습니다.

앱 내 삭제 메뉴 종료

이전 버전의 설정 > 기존 클라우드 데이터 삭제 메뉴는 삭제할 대상이 남아 있지 않아 최신 버전에서 제거되었습니다. Firebase Authentication의 로그인 제공자를 비활성화해 이미 설치된 이전 버전 앱에서 로그인해도 새 계정이나 업로드가 만들어지지 않습니다.

이메일로 삭제 요청

본인의 온라인 데이터가 남아 있다고 생각되면 support.minsukkim@gmail.com으로 “나물대사전 기존 클라우드 데이터 삭제”를 요청해 주세요. 예전에 사용한 계정의 제공자(Apple 또는 Google)와 이메일을 알려 주되 비밀번호·인증코드는 보내지 마세요. 운영자는 본인 확인에 필요한 최소 정보만 추가 요청하고 지체 없이 처리합니다.

삭제된 온라인 데이터

• Firebase Realtime Database의 diary/{uid}: 이전 일기 본문·날짜·활동 유형·연결한 나물·위치 좌표·주소·사진 경로
• Firebase Storage의 diary/{uid}/**: 이전 온라인 일기 사진
• Firebase Authentication 계정: Firebase uid, 제공자 연결과 이메일(제공된 경우)

위 항목은 2026년 9월 15일 기준 모두 삭제되었으며 운영자는 별도의 보관본을 만들지 않았습니다.

삭제되지 않는 데이터와 별도 보유기간

• 이 기기의 일기와 사진은 삭제되지 않습니다. 앱에서 별도로 관리·삭제해야 합니다.
• Firebase Analytics 사용자·이벤트 수준 데이터는 운영자 설정 기준 최대 14개월, Sentry 오류·성능 이벤트는 최대 90일 보관될 수 있습니다. 이는 클라우드 일기 계정과 별도의 SDK 처리이며, 광고·분석 데이터는 Google·Sentry 정책과 이용자 선택에 따라 처리됩니다.
• 법적 의무·보안·분쟁 대응을 위해 별도 보존이 필요한 기록은 해당 목적과 기간에 한해 보관한 뒤 삭제합니다.
