studio-hq(이하 "서비스")는 Minsuk Kim(이하 "운영자")이 자신이 운영하는 YouTube 채널과 소셜 계정에 직접 만든 영상과 글을 예약 게시하기 위해 쓰는 내부 도구입니다. 일반 이용자에게 가입을 받지 않으며, 연결되는 Google 계정은 운영자 본인이 소유한 계정뿐입니다.

서비스에는 광고, 이용 분석(애널리틱스), 제3자 추적 도구가 없습니다.

1. Google 사용자 데이터에 접근하는 방법과 범위

운영자가 Google 로그인 화면에서 동의하면 서비스는 다음 OAuth 범위로 YouTube Data API v3에 접근합니다.

  • https://www.googleapis.com/auth/youtube.upload: 운영자의 채널에 영상을 업로드하고 공개 예약 시각을 정합니다.
  • https://www.googleapis.com/auth/youtube: 연결된 채널의 ID를 확인하고, 업로드한 영상의 공개 상태·예약 시각·썸네일·재생목록을 관리합니다.

2. 처리하는 항목

  • OAuth 토큰: 액세스 토큰과 리프레시 토큰. 운영자 채널에 게시하는 데만 쓰며, 화면이나 로그에 출력하지 않습니다.
  • YouTube 채널 ID: 토큰이 의도한 채널의 것인지 확인하는 데 씁니다.
  • 업로드한 영상의 정보: 영상 ID, 공개 상태, 예약 시각, 그리고 운영자가 직접 작성한 제목·설명·태그.

서비스는 시청자 정보, 댓글, 구독자 목록, 다른 채널의 데이터를 읽거나 저장하지 않습니다.

3. 이용 목적과 제한

Google API에서 받은 정보는 운영자 자신의 채널에 콘텐츠를 게시하고 그 상태를 확인하는 데만 씁니다. 서비스가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 정보를 판매하거나, 광고에 쓰거나, AI 모델 학습에 쓰거나, 제3자에게 제공하지 않습니다.

4. 보관 위치와 위탁

5. 보유 기간과 삭제

  • OAuth 토큰: 채널 연결을 해제할 때까지. 해제할 때 운영자가 저장소에서 삭제합니다.
  • 게시 기록: 서비스를 운영하는 동안 보관하며, 운영을 종료하면 삭제합니다.
  • 언제든 Google 계정의 서드파티 액세스 관리에서 studio-hq의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없습니다.

6. 안전성 확보 조치

  • 모든 전송은 TLS로 암호화됩니다.
  • 관리 기능은 운영자 인증 토큰으로만 접근할 수 있고, 토큰 값은 응답과 로그에 남기지 않습니다.
  • 작업용 서버에는 게시 권한이 없는 토큰만 두고, 채널 토큰은 서비스 저장소에만 보관합니다.

Summary in English

studio-hq is an internal tool that Minsuk Kim uses to schedule videos and posts on YouTube channels and social accounts the operator owns. It does not accept sign-ups; the only Google accounts connected are the operator's own.

With the operator's consent, studio-hq uses the YouTube Data API v3 scopes youtube.upload and youtube to upload videos to the operator's channel, set their publish time, thumbnail and playlist, and confirm the connected channel ID. It stores the OAuth access and refresh tokens, the channel ID, and the metadata of videos it uploads, on Cloudflare (Workers, D1, KV, R2). It does not read or store viewer data, comments, subscriber lists or other channels' data.

studio-hq's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The data is never sold, used for advertising, used to train AI models, or shared with third parties.

The operator deletes a channel's tokens from storage when disconnecting it. Access can be revoked at any time at Google Account third-party access. Contact: support.minsukkim@gmail.com.
