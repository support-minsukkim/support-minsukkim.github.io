`com.geotime.recorder`), served via GitHub Pages for the Google Play / App Store
listings and AdMob.

- Privacy Policy → [`privacy.html`](https://support-minsukkim.github.io/arrivo/privacy.html)
- Terms of Use → [`terms.html`](https://support-minsukkim.github.io/arrivo/terms.html)
- Support → [`support.html`](https://support-minsukkim.github.io/arrivo/support.html)
- Ad Report → [`ad-report.html`](https://support-minsukkim.github.io/arrivo/ad-report.html)
- Data Deletion → [`data-deletion.html`](https://support-minsukkim.github.io/arrivo/data-deletion.html)

Source-of-truth references live in the app repo:

- Data practices: `docs/PRIVACY_POLICY_DRAFT.md`
- In-app privacy/terms contract: iOS `SettingsDocuments.swift`, Android
  `PrivacySettingsPolicy.kt` and `AboutPolicy.kt`
- Premium entitlements: iOS/Android `PremiumPaywallCopy`

When those references change, update these public pages in the same release and
verify that free-tier limits and every enabled ad format still match the app.
